FAQ

Where are my files saved?

Wherever you created or opened them: On My iPhone/iPad, iCloud Drive, or another provider in the Files app. Txt edits the original file in place, not a copy.

How do I open a file from Dropbox, Google Drive or another app?

Enable that provider in the Files app (Browse → ⋯ → Edit), then open the file from Txt's document browser.

Which file types are supported?

Plain text (.txt) and Markdown (.md, .markdown, .mdown). You can export any document as .txt, .md or .csv from the ⋯ menu.

How do I preview Markdown?

Open a Markdown file, tap ⋯ and choose Preview Markdown.

How do I find and replace text?

Tap ⋯ → Find & Replace, or the search key on the keyboard row. Use the arrows to jump between matches, or Replace / All.

How do I back up my documents?

Store them in iCloud Drive or another cloud provider, or use Share / Export As to send copies elsewhere.

How do I delete my data?

Delete documents in the Files app. Txt keeps no data on any server, so there is nothing else to remove.

Can I open two documents side by side on iPad?

Yes. Txt supports multiple windows, so you can use Split View with two documents.

Requirements

iPhone or iPad running iOS / iPadOS 17.0 or later.
